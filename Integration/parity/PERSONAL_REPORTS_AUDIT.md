# Native personal reports and coach

26 October 2026. Implemented against Core `5c7601d`'s bounded sleep-record query and aggregate-vitals provenance. No legacy analytics/AI route is used for Core reports, coaching or the summary Shortcut. Release version remains 0.2.0 (7).

The existing settings and Sleep entry points preserve native Sleepypod grouped components. Coach retains 7/30/90-day selection, descriptive local calculations with no model/sharing, plus the chosen-model path. Reports keep a 30-day Pod summary. Health history is independently selectable and retains its own dated range; it does not inherit the Pod-range filter. Demo evidence is explicitly synthetic and never dispatches a model request.

NativeSleepEvidence freezes the endpoint/owner and reads settings for the Pod timezone. Complete range-split record loading includes 16 hours before the lower bound, then excludes ongoing, malformed, short (<20 minutes) and stuck (>=16 hours) records. Wrong-side/time/duplicate identities fail. It clips and unions disjoint presence intervals, preserving exits/removing overlap, and groups coverage by completed wake date. Presence is never relabeled measured sleep. Empty coverage is unknown, not zero sleep. The reusable service feeds the thirty-day summary Shortcut and native evidence bridge.

Vitals use the server aggregate, not an unbounded raw 90-day transfer. Facts state that the range aggregate is not restricted to sleep or occupied intervals. Original-observation configuration counts and missing provenance remain visible. Only compatible recorded hrv_sdnn is called SDNN; unknown, mixed-definition and other metrics are excluded from SDNN facts. Seven fixture cases were generated by the real Core summarizer/schema, without running its server or database. No private journal notes are included.

Evidence reads use generation/owner/side/range cancellation guards. Model requests capture provider, model, address, question, source name and exact reviewed evidence. Explicit per-request external-sharing consent resets when inputs change; caller validity is rechecked before archive publication. Cancelled/late/changed-scope replies never archive as a current report. Local archive remains file-protected. The prompt makes no actuator calls. Keys/raw Health samples are not put into prompt text.

Both UI flows pass on iPhone (`NativeReports-phone-v9`) and iPad (`NativeReports-ipad-v6`). Maximum-text report and coach flows pass (`NativeReports-AX-v7` and `NativeReports-AX-v10`); 21 retained captures were reviewed. The final maximum-text run also passes all 5 journal/coaching regressions and 4 evidence/consent checks. Native scrolling and adaptive menu pickers keep the controls available at accessibility text sizes.

The final compiler compatibility change splits the journal association calculation into explicit sums and means, preserving minimum group sizes and rounding. Remote Xcode 26.3 checks remain required.
