# Native parity release notes

Published for internal TestFlight 0.3.0 (8) on 26 October 2026. The saved What to Test text follows the feature checklist below; final assignment evidence is in `build8.md`.

## What to test

Sleepypod's original Temp, Schedule and Sleep interface now includes the web app's controls and diagnostics, with the personal features available from native detail screens.

- Switch between temperature Cards and the interactive bed Stage. Try Degrees, Offset and Eight Sleep scales, side selection, sensor layers, schedule preview and camera reset.
- Review bed position, mattress/frame display, head and feet controls, presets and base schedules on a supported connected base.
- Edit a bedtime routine, temperature curve or wake alarm. Try changing, skipping and restoring just the next alarm.
- Browse sleep nights, biometrics, Watch comparisons, morning check-ins and personal reports. Health export is optional and uses the selected data permissions.
- Explore Autopilot planning, rule editing, replay and diagnostics, plus the System and Settings sections.
- On a compatible controller, inspect Personal comfort qualification, matching reviewed nights and expiring owner reviews. Synthetic examples cannot activate real comfort or confirm physical checks.
- Check iPhone and iPad layouts, light/dark appearance, larger text, disconnected states and reconnection.

Please include the screen, selected side and exact action when reporting a problem. A command acknowledgment alone does not confirm physical bed movement or temperature delivery.
