# Bedtime audio: native extension

Mode: Operate, with an embedded Read guide. This extends the existing Tonight
and personal-account surfaces using their SwiftUI navigation, semantic Theme
colors, system text styles and grouped forms. It does not replace the app's
visual identity. The incumbent quiet-time screen and the rendered next-alarm
screen were inspected before editing.

## User task and hierarchy

The approved task is one explicit Endel bedtime handoff with selected mode,
bedside speakers, volume and timer, plus an honest result and manual recovery.
The original requested volume is 35 percent. Setup names and a 60-minute timer
are editable starting suggestions, not verified installed Shortcuts.

- Enter from Tonight or the personal account's Wind down section.
- A focused, dismissible sheet retains one session outside the presentation.
  Dismissing it does not claim audio stopped or discard a pending result.
- First use explains the two saved Shortcuts and links to their preparation.
- Later visits lead with the latest handoff, if one exists, followed by the
  reviewed settings and Start. An unreviewed result disables a duplicate Start.
- Shortcut completion and a user's speaker observation are separate lines.
- Pause asks whether this is still the session the person started; direct Endel
  instructions remain available for calls, a changed route or failed actions.
- Missing account/quiet state provides an actionable connection message.

## Direction contract

Keep native Form rows, NavigationStack back behavior and ordinary system
transitions. No animated playback indicator, waveform or green success mark
suggests measured speaker state. Use one restrained tint, text-plus-symbol
status, 44-point action targets and uncropped Dynamic Type. Error and recovery
belong beside the action they describe. Keep the guide below the everyday task,
with the most important setup limitation before any confirmation.

Verify real simulator renders on iPhone and iPad, light and dark appearances,
largest accessibility text and iPad landscape. Exercise initial setup,
unconfirmed completion, user observation, Pause confirmation, shared quiet,
unavailable connection and lost callback. Synthetic previews must label that no
speakers are connected. They do not count as Endel/HomePod qualification.

No design-system replacement, new brand claims or proprietary Endel API is part
of this extension. No web/CSS detector applies to these native files; the final
independent reviewer receives the iOS and craft-floor references.
